## Инструкция по получению сервисного ключа VK API

1. Перейти по ссылке https://dev.vk.ru/ru/admin/create-app.
   Создать приложение с любым названием, нажать **Создать**.

2. Найти приложение в перечне https://dev.vk.ru/ru/admin/apps-list.
   Зайти в **Настройки**, в меню слева выбрать **Разработка**, затем – **Ключи доступа**.

   Нам понадобится **сервисный ключ**. Нажимаем **Показать**, приходит SMS с кодом подтверждения, подтверждаем, ключ открывается для копирования.
